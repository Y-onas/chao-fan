Every visual in the builder falls into one of three groups. Anything not marked
**production-ready** should be replaced before a polished launch.

into `public/assets/food/`. Each colour image has a matching `_h` height map for relief.

## Still needed for production

These need a photographer, a 3D artist, or external image/3D generation tools; they
cannot be derived from the current references:

1. **Beef Chaofan** — a clean top-down photo (or close-ups of the beef pieces) to replace the modelled beef.
2. **Chicken leg** — a well-lit close-up to replace the current dark cut-out.
3. **Egg and Veggie Chaofan** — reference photos of the real dishes.
4. **Drinks** — photos or models of each drink actually sold (the menu prices are also unset until the owner fills them in at `#/admin`).
5. **Branded takeaway packaging** — the real box/bag and logo artwork.
6. **Logo** — the header currently uses a "CF" monogram.

To swap a photo-derived asset: replace the file in `assets-src/references/`, adjust its crop box
in `scripts/extract_assets.py`, run `npm run assets` (needs `pip install pillow numpy scipy opencv-python-headless`).
